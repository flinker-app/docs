Edit IFC placement

The native IFC API edits georeferencing in memory before the models are displayed.

Open Files (folder) on the left toolbar. Toggle the checkbox beside OMG_KS_3dBAG.ifc to show or hide the neighbouring buildings. Select a component, then click 1 element selected at the top left to open Properties.
